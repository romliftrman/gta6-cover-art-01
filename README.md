Neon Shore Cover Studio — a GTA 6-style cover art maker: your photos become a 9-panel poster with 9 neon sunset grades, 3 layouts, face-aware crops, undo/redo, and PNG export in 3 post sizes (1080×1080, 1080×1350, 1920×1080). Runs fully offline in the browser; photos never leave your device.

## Run it

```sh
python3 -m http.server 8080 --directory app
# open http://localhost:8080
```
